# Blog de la Academia de Finanzas · maqueta V2

Producto mínimo para evaluar la propuesta del Blog de la Academia de Finanzas del Departamento de Administración (Universidad de Sonora). Es una propuesta para discusión: no es el sitio oficial ni está autorizada por la Coordinación de Identidad Institucional.

- Sitio: páginas estáticas (HTML, CSS y JavaScript), publicadas con GitHub Pages.
- Herramientas: los botones «Abrir herramienta» llevan a las herramientas publicadas en eduardosalas.com.
- Identidad visual: Manual de Identidad Institucional UNISON 2025-2030.
- Integrantes: página de la Academia de Finanzas en administracion.unison.mx (consulta del 10/11/2026).
- Documentación de la maqueta: `documentacion/`.
